종이 위의 길 (Ink Trail)

플레이어가 종이 위에 펜으로 선을 그어 잉크 캐릭터의 이동 경로를 만들고, 제한된 잉크 안에서 장애물을 피해 목적지까지 도달시키는 경로 드로잉 퍼즐 게임입니다.

프로젝트 개요
장르: 경로 드로잉 퍼즐 (2D 스타일 연출 + 3D Plane 기반)
개발 기간: 2026.07.06 ~ 2026.07.10 (2026 청강게임대전 게임프로그래밍 부문 출품작)
개발 인원: 1명
사용 엔진: Unity 6.3 LTS
사용 언어: C#
출시 플랫폼: PC (Windows Standalone)
담당 역할: 기획, 프로그래밍, UI 구성, 테스트, 빌드 (1인 개발)

게임 설명

플레이어는 시작점과 목적지 사이에 직접 선을 그어 잉크 캐릭터의 이동 경로를 만듭니다. 잉크(이동 가능 거리)는 제한되어 있어, 최단 경로를 고민하며 찢어진 종이 형태의 장애물을 피해야 합니다.

스테이지가 진행될수록 단순히 맵이 커지는 것이 아니라 이동 규칙 자체가 확장되도록 구성했습니다.

1스테이지 — 기본 규칙: 제한된 잉크 길이 안에서 장애물을 우회해 시작점과 목적지를 연결
2스테이지 — 라이터 기믹: 라이터를 획득해 종이 위로 드래그하면 반경 안의 숨겨진 경로가 지점별로 서서히 드러남
3스테이지 — 포탈 기믹: 잉크 얼룩 모양의 두 지점이 포탈로 연결되어, 한쪽에 닿으면 순간이동하며 경로가 이어짐

주요 기능
마우스 드래그 기반 경로 드로잉 및 Catmull-Rom 스플라인 곡선 렌더링
잉크 소모량(누적 이동 거리) 계산 및 잔여량 판정
장애물 우회 판정, 목적지 도달 판정
라이터를 이용한 숨겨진 경로 단계적 드러내기 (2스테이지)
포탈을 통한 구간 순간이동, 1회성 사용 제한 (3스테이지)
스테이지 클리어/실패 처리 및 재시작
디버그 콘솔(레벨 강제 스킵, 실시간 퍼즐 데이터 출력)

조작법
선 그리기: 마우스 드래그
경로 이동 실행: Move 버튼
다시 그리기: Reset 버튼

개발 과정
대회 주제(퍼즐) 확정 후 경로 드로잉 컨셉 기획
스플라인 기반 선 그리기 및 캐릭터 이동 프로토타입 제작
잉크 소모 판정, 장애물 우회 판정 등 1스테이지 규칙 구현
라이터(2스테이지), 포탈(3스테이지) 기믹 순차 추가
씬 전환 구조 및 매니저 자동 재바인딩 설계
디버그 콘솔 구현, 플레이 테스트 및 난이도 조정
빌드 및 대회 출품

기술적으로 신경 쓴 부분
경로 렌더링: 마우스로 입력된 원본 좌표들을 Catmull-Rom 스플라인(4점 보간)으로 변환해 매끄러운 곡선으로 렌더링했습니다.
판정 로직 일관성: 잉크 소모량, 라이터 반경, 목적지 도달, 선분 겹침 등 게임 전반의 판정에 유클리드 거리 계산을 반복적으로 활용해 로직을 통일했습니다.
경로 유효성 검증: 플레이어가 그린 여러 선분(Segment)을 그래프의 노드처럼 다루고, 선분 간 연결 여부를 간선처럼 판정해 캐릭터가 항상 유효한 경로로만 이동하도록 구성했습니다.
씬-매니저 구조 분리: GameManager, InputManager, PathManager, CharacterMover 등 핵심 매니저는 최초 씬에서 한 번 생성되어 DontDestroyOnLoad로 유지되고, 씬이 전환될 때마다(Scene.sceneLoaded) 새 씬의 오브젝트를 이름으로 탐색해 자동으로 다시 연결하도록 만들어, 매니저의 생명주기와 씬별 오브젝트의 생명주기를 분리했습니다.
포탈 연결 구조: 두 포탈이 서로를 참조하는 1:1 연결 구조로 구성하고, 한쪽이 사용되면 즉시 잠기는 1회성 간선으로 처리해 재사용을 방지했습니다.

문제 해결 경험
문제 1. 캐릭터 이동 시 경로 색상 갱신이 이동 속도를 따라가지 못하는 문제
원인: 캐릭터가 이동할 때마다 지나간 구간의 색을 처음부터 다시 그리는 방식으로 처리해, 색 변화가 캐릭터의 실제 이동보다 느리게 나타남
해결: 선 전체를 매번 다시 그리는 대신, 현재 위치까지 이동한 거리를 계산해 그만큼의 구간만 색을 갱신하도록 수정
배운 점: 같은 결과를 만들더라도 데이터를 어떤 방식으로 관리하고 갱신하느냐에 따라 게임 성능에 큰 차이가 생긴다는 것을 알게 됨

AI 활용 내용

이 프로젝트에서는 AI(Claude)를 다음 작업에 활용했습니다.

퍼즐 메커닉 아이디어 논의 및 스테이지별 규칙 설계
C# 스크립트(GameManager, InputManager, PathManager, CurveDrawer, CharacterMover 등) 초안 작성 및 디버깅 보조
잉크 캐릭터, 목표 지점, 장애물, 포탈, 라이터 등 벡터(SVG) 아이콘 초안 제작
기술 명세서 및 발표 자료 작성 보조

AI가 제안한 코드는 바로 적용하지 않고 프로젝트 구조에 맞는지 검토한 뒤 테스트했으며, 최종 로직 설계와 검증은 직접 수행했습니다.
